## 🔧 优化细节

### 1. E1加权公式优化（已完成）

**优化前逻辑：**
```python
# 简单布尔计数：60秒内有编辑 = 1，否则 = 0
if has_edit_within_60s:
    edit_after_ai += 1
```

**优化后逻辑：**
```python
# 加权 + 滑动衰减窗口（120秒）
时间窗口权重：
  0-30s:  1.0
  30-60s: 0.8
  60-120s: 0.5

编辑深度权重：
  深度 = depth × 0.7 + 0.3

最终得分 = 时间权重 × 编辑深度权重
```

**效果：**
- ✅ 理论合理：越早编辑 + 越深层编辑 = 越高的Evaluation
- ⚠️ 实际偏差：低元认知场景E过度下降（0.250→0.075）

**原因分析：**
低元认知场景的3次编辑都是浅层编辑（错别字、复制粘贴），加权后得分被压得过低。

**建议微调：**
```python
# 调整基础权重，避免浅层编辑得分过低
weighted_score = weight * (0.5 + 0.5 * depth)  # 从(0.3+0.7*depth)改为(0.5+0.5*depth)
```
