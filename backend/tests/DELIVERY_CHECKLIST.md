## ⚠️ 已知问题与优化计划

### P1 - 高元认知Evaluation偏低（0.447 vs 期望>0.7）

**根本原因：** E1（AI回复后编辑率）= 0.0
- E1在60秒窗口内寻找编辑事件
- 模拟数据中编辑发生在AI回复后62秒（超出窗口）

**解决方案：**
1. **今日完成**：E1加权公式 `E1_weighted = E1 * (0.3 + 0.7 * E2)`
2. **本周完成**：E1改为滑动衰减（0-30s权重1.0，30-60s权重0.8，60-120s权重0.5）

**优先级：** 🔴 高（影响高元认知学生判断）

---

### P2 - 低元认知Monitoring偏高（0.613 vs 期望<0.4）

**根本原因：** M2（区域切换）基线值0.1仍得0.94高分

**详细分析：**
```
当前参数：normalize_gaussian(0.1, optimal=0.15, sigma=0.15)
问题：基线值0.1与optimal 0.15距离较近，得分虚高

建议调整：
- optimal: 0.15 → 0.20
- sigma: 0.15 → 0.12
预期效果：0.1 → 约0.5分（更合理）
```

**优先级：** 🟡 中（影响低元认知学生判断）

---

### P3 - 部分特征依赖启发式规则

**当前状态：**
- P2（Prompt目标明确度）：关键词匹配
- E2（编辑深度）：关键词匹配

**问题：** 规则可能无法覆盖所有表达方式

**解决方案：**
- **短期**：增加更多关键词模式
- **中期**：升级为LLM判断（Claude 3 Haiku）

**优先级：** 🟢 低（当前规则基本可用，真实数据测试后再决定）
