## 四、剩余问题与解决路径

### P1 - 高元认知的Evaluation偏低（0.447）

**期望：** > 0.7  
**实际：** 0.447  
**原因分析：**

E维度分解：
- E1（AI回复后编辑率）：0.0 ❌
- E2（编辑深度）：1.0 ✅
- E3（自主编辑比例）：0.33 ⚠️
- E4（验证频率）：0.2 ✅

**根本原因：** E1计算逻辑存在缺陷
- 当前公式：`edit_after_ai / len(ai_replies)`（二元判断：60秒内有/无）
- 问题：模拟数据中编辑在62秒发生 → E1=0，导致整体E分数崩塌

**解决方案（优先级排序）：**

1. **立即（10分钟）：** 调整模拟数据时间，确保高元认知学生的编辑发生在45秒
2. **短期（今日）：** E1加权公式改进
   ```python
   # 当前：E1不区分编辑质量
   e1 = edit_rate
   
   # 改进：结合编辑深度
   e1_weighted = edit_rate * (0.3 + 0.7 * avg_edit_depth)
   # 这样浅层复制粘贴不会虚高评分
   ```
3. **中期（本周）：** E1改为滑动衰减
   ```python
   # 0-30秒: 权重1.0
   # 30-60秒: 权重0.8
   # 60-120秒: 权重0.5
   # >120秒: 权重0.2
   # 这样60秒外的编辑仍有贡献
   ```

### P2 - 低/中等元认知的Monitoring偏高（0.61-0.63）

**期望：** < 0.4（低）/ 0.4-0.6（中）  
**实际：** 0.613（低）/ 0.603（中）  
**改善：** 已从0.70/0.90降到0.61/0.60 ✅ 但仍需微调

**细分原因（低元认知）：**
- M1（阅读3秒）：0.53（sigma=10后，已从0.84降低 ✅）
- M2（区域切换0.1）：0.94（基线值，符合预期）
- M3（追问0）：0.60
- M4（指错0）：0.37

**进一步优化方案：**
