**解决方案：**
需要调整模拟数据生成器，让高元认知学生的第一次编辑发生在AI回复后30-50秒内。

## 剩余问题

### P1 - Evaluation指标仍需优化

**问题1：E1时间窗口虽扩展到60秒，但模拟数据的编辑时间仍超出窗口**
- 当前：AI回复 → 15秒阅读 → 2秒切换 → 5秒编辑 = 总共22秒 ✓
- **实际问题：** 查看代码发现，模拟数据中时间累加有误

**问题2：E1未结合E2加权**
- 低元认知学生快速复制（E1=1.0但E2=0.0）也被算作高Evaluation
- 建议公式：`E1_weighted = E1 * (0.3 + 0.7 * E2)`
- 这样浅层编辑的E1权重会被降低

**问题3：低元认知的Monitoring仍偏高（0.700）**
- 期望<0.4，实际0.700
- 原因：E1=1.0（虽然是浅层编辑，但被归入Monitoring的一部分）
- **重要发现：** 代码中E1被用于Evaluation计算，不影响Monitoring，所以0.700来自M1/M2/M3/M4

让我检查Monitoring的计算逻辑：

**低元认知的Monitoring细节：**
- M1（阅读时长）= 3秒 → normalize_gaussian(3, optimal=15, sigma=20) ≈ 0.84（因为高斯函数在optimal附近才高分，3秒偏离15秒较远，但sigma=20太大，导致分数仍较高）
- M2（区域切换）= 0.1（基线）→ normalize_gaussian(0.1, 0.15, 0.15) ≈ 0.94
- M3（追问）= 0 → normalize_gaussian(0, 0.2, 0.15) ≈ 0.60
- M4（错误）= 0 → normalize_gaussian(0, 2, 2) ≈ 0.37

平均：(0.84 + 0.94 + 0.60 + 0.37) / 4 = 0.69 ✓ 接近0.700

**根本问题：高斯函数参数需要进一步调优**
- M1的sigma=20太大，导致3秒仍得0.84高分
- 建议调整：sigma=10，使得3秒 → 约0.4分
