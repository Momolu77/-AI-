## 详细分析

### 1. 高元认知学生会话

**行为特征：**
- 先阅读任务说明120秒（P4高）
- 60秒后发送首个Prompt（P1适中）
- Prompt目标明确，包含3步拆解（P2/P3高）
- AI回复后平均阅读13.75秒（M1适中）
- 频繁切换区域对比（M2高）
- 指出AI错误1次（M4中等）
- 深度编辑AI内容（E2高）
- 验证行为频繁（E4高）

**PME分数：**
- **Planning: 0.900** ✓ 符合预期（>0.7）
- **Monitoring: 0.781** ✓ 符合预期（>0.7）
- **Evaluation: 0.447** ✗ 低于预期（期望>0.7）

**原因分析：**
- Evaluation偏低是因为 **E1（AI回复后编辑率）为0**
- 模拟数据中AI回复后**30秒内**没有edit事件，导致E1=0
- 实际上学生有深度编辑行为（E2=0.667），但时间超过了30秒窗口

**修正建议：** 将E1的时间窗口从30秒扩展到60秒，或调整模拟数据的时间间隔。

---

### 2. 低元认知学生会话

**行为特征：**
- 不查看任务说明（P4=0）
- 5秒后直接询问AI（P1极低）
- Prompt目标模糊（P2=0）
- 无任务拆解（P3=0）
- AI回复后平均阅读3秒（M1极低）
- 无区域切换（M2=0.1基线）
- 无追问（M3=0）
- 快速复制AI内容（E1=1但都是浅层编辑E2=0）
- 无验证行为（E4=0）

**PME分数：**
- **Planning: 0.243** ✓ 符合预期（<0.4）
- **Monitoring: 0.684** ✗ 高于预期（期望<0.4）
- **Evaluation: 0.250** ✓ 符合预期（<0.4）

**原因分析：**
- Monitoring偏高是因为 **E1（AI回复后编辑率）为1.0**
- 虽然编辑是浅层的，但"每次AI回复后都有编辑"使得E1达到满分
- 这暴露了E1指标的局限：它无法区分"浅层快速复制"和"深度加工"

**修正建议：** E1应结合E2使用，或者E1的计算中加入编辑深度权重。

### 3. 中等元认知学生会话

**行为特征：**
- 简单查看任务30秒（P4中等）
- 30秒后发送Prompt（P1中等）
- Prompt目标不够明确（P2=0）
- 无任务拆解（P3=0）
- AI回复后阅读7秒（M1中等）
- 区域切换频繁（M2高）
- Prompt数<3，无法计算M3/M4（insufficient_data）

**PME分数：**
- **Planning: 0.376** ✓ 符合预期（约0.4）
- **Monitoring: 0.903** ✗ 高于预期（期望约0.4）
- **Evaluation: 0.250** ✓ 符合预期（约0.5偏低）

**原因分析：**
- Monitoring极高是因为 **M2（区域切换）为0.2，接近最优值0.15**
- 高斯标准化使得0.2得分很高
- 但M3/M4因为Prompt数不足而无法计算，导致Monitoring只基于M1/M2

**修正建议：** 增加Prompt数量，或调整高斯函数的sigma参数使其更宽容。

## 问题汇总与修正建议

### P0 - 必须修正

1. **E1时间窗口过窄**
   - 当前：AI回复后30秒内
   - 建议：扩展到60秒，或使用动态窗口
   - 影响：高元认知学生的Evaluation分数被低估

2. **特征覆盖率显示错误**
   - 当前：所有场景显示0.0%
   - 实际：应该是100%或83%
   - 原因：`all_features`列表构建有误
   - 修正：检查`compute_metacog_state`中的特征收集逻辑

### P1 - 建议修正

3. **E1无法区分浅层和深度编辑**
   - 当前：只看"是否编辑"，不看"编辑质量"
   - 建议：E1 = (有编辑的AI回复数 / 总AI回复数) * E2_平均深度
   - 影响：低元认知学生的Evaluation分数被高估

4. **高斯标准化过于敏感**
   - 当前：M2的最优值0.15，sigma=0.1
   - 问题：0.2已得到0.9+高分
   - 建议：增大sigma到0.15，使分数曲线更平缓

5. **Prompt数<3时M3/M4无法计算**
   - 当前：标记为`insufficient_data`
   - 问题：会话初期Monitoring置信度低
   - 建议：Prompt数≥2时就计算，或使用滑动窗口
