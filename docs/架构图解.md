## 数据流图

### 1. 用户输入 → AI回复流程

```
用户输入 Prompt
    │
    ├─ 1. WebSocket 发送
    │     {event_type: "prompt", content: "..."}
    │
    ▼
FastAPI WebSocket Handler
    │
    ├─ 2. 保存到 interaction_logs 表
    │     INSERT INTO interaction_logs (...)
    │
    ├─ 3. 调用 state_recognizer.compute_metacog_state()
    │     │
    │     ├─ 提取特征: prompt_length, question_words, ...
    │     │
    │     ├─ 计算状态: planning, monitoring, evaluation
    │     │
    │     └─ 返回: {planning: 0.65, monitoring: 0.42, evaluation: 0.58}
    │
    ├─ 4. 保存到 metacog_states 表
    │     INSERT INTO metacog_states (...)
    │
    ├─ 5. 缓存到 Redis
    │     SET state:{session_id} {...} EX 3600
    │
    ├─ 6. 推送状态更新到前端
    │     WebSocket.send({type: "state_update", data: {...}})
    │
    ├─ 7. 调用 intervention.decide_intervention()
    │     │
    │     ├─ 检查低水平: planning < 0.3 && 持续3次?
    │     │
    │     ├─ 检查波动: |Δplanning| > 0.4?
    │     │
    │     └─ 返回: InterventionDecision 或 None
    │
    ├─ 8. 如果需要干预
    │     │
    │     ├─ 调用 ai_generator.generate_intervention()
    │     │     └─ Anthropic API Call
    │     │           └─ 返回干预内容
    │     │
    │     ├─ 保存到 interventions 表
    │     │     INSERT INTO interventions (...)
    │     │
    │     └─ 推送到前端
    │           WebSocket.send({type: "intervention", data: {...}})
    │
    ├─ 9. 调用 ai_generator.chat_with_ai()
    │     │
    │     └─ Anthropic API Call
    │           └─ 返回对话回复
    │
    └─ 10. 推送 AI 回复到前端
          WebSocket.send({type: "ai_reply", data: {content: "..."}})
          │
          ▼
前端接收并展示
    │
    ├─ ChatInterface: 显示 AI 回复
    │
    ├─ StateVisualization: 更新状态卡片和曲线
    │
    └─ 如果有干预: 弹出 Alert 提示
```

## 状态识别算法流程

```
输入: 最近 N 条交互日志
    │
    ▼
┌─────────────────────────────────────┐
│      特征提取 (_extract_features)    │
│                                     │
│  - prompt_length: len(content)      │
│  - question_words: count("什么/如何/为什么") │
│  - edit_frequency: edits / total    │
│  - reflection_words: count("思考/评估/反思") │
│  - time_gap: Δt between actions     │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│      状态计算 (compute_metacog_state)│
│                                     │
│  Planning = min(1.0,                │
│    prompt_length/200 * 0.4 +        │
│    question_words/3 * 0.3 +         │
│    (1 - edit_frequency) * 0.3       │
│  )                                  │
│                                     │
│  Monitoring = min(1.0,              │
│    edit_frequency * 0.5 +           │
│    verify_count/5 * 0.3 +           │
│    time_consistency * 0.2           │
│  )                                  │
│                                     │
│  Evaluation = min(1.0,              │
│    reflection_words/5 * 0.6 +       │
│    self_assessment * 0.4            │
│  )                                  │
└──────────────┬──────────────────────┘
               │
               ▼
输出: {planning: [0-1], monitoring: [0-1], evaluation: [0-1]}
```

## 干预决策算法流程

```
输入: 当前状态 + 历史状态列表
    │
    ▼
┌─────────────────────────────────────┐
│    策略1: 低水平持续检测              │
│                                     │
│  FOR dim IN [P, M, E]:              │
│    IF current[dim] < 0.3:           │
│      recent = history[-3:]          │
│      IF all(s[dim] < 0.3 for s in recent): │
│        → 触发干预                    │
│           type: "metacog_prompt"    │
│           dimension: dim            │
│           reason: "{dim} 持续低水平" │
└──────────────┬──────────────────────┘
               │ 如果未触发
               ▼
┌─────────────────────────────────────┐
│    策略2: 状态波动检测                │
│                                     │
│  IF len(history) >= 2:              │
│    prev = history[-1]               │
│    FOR dim IN [P, M, E]:            │
│      delta = |current[dim] - prev[dim]| │
│      IF delta > 0.4:                │
│        → 触发干预                    │
│           type: "process_scaffold"  │
│           dimension: dim            │
│           reason: "{dim} 剧烈波动"   │
└──────────────┬──────────────────────┘
               │ 如果未触发
               ▼
┌─────────────────────────────────────┐
│    策略3: 策略建议                   │
│                                     │
│  基于当前状态模式:                   │
│  - 高P低M → 建议监控执行过程         │
│  - 高M低E → 建议自我评估             │
│  - 低P高M → 建议先做计划             │
└──────────────┬──────────────────────┘
               │
               ▼
输出: InterventionDecision 或 None
```

## WebSocket 消息协议

### 客户端 → 服务端

```json
// 事件类型1: Prompt
{
  "event_type": "prompt",
  "content": "用户输入的文本"
}

// 事件类型2: Edit
{
  "event_type": "edit",
  "content": "编辑的内容描述"
}

// 事件类型3: Verify
{
  "event_type": "verify",
  "content": "验证行为描述"
}
```

### 服务端 → 客户端

```json
// 消息类型1: AI回复
{
  "type": "ai_reply",
  "data": {
    "content": "AI生成的回复内容"
  }
}

// 消息类型2: 状态更新
{
  "type": "state_update",
  "data": {
    "planning": 0.65,
    "monitoring": 0.42,
    "evaluation": 0.58,
    "timestamp": "2026-09-14T10:30:00Z"
  }
}

// 消息类型3: 干预
{
  "type": "intervention",
  "data": {
    "type": "metacog_prompt",
    "dimension": "planning",
    "content": "检测到您的计划性较低，建议先...",
    "triggered_by": "planning 持续低水平"
  }
}
```
