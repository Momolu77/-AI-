#### 1.3 服务层

**状态识别模块** (`state_recognizer.py`)
```python
特征提取:
- prompt_length: 输入长度
- question_words: 疑问词数量
- edit_frequency: 编辑频率
- reflection_words: 反思性词汇
- time_gap: 行为间隔

状态计算:
- planning = f(prompt_length, question_words, ...)
- monitoring = f(edit_frequency, time_gap, ...)
- evaluation = f(reflection_words, ...)
```

**干预决策模块** (`intervention.py`)
```python
触发条件:
1. 低水平干预: state < 0.3 且持续 3 次
2. 波动干预: |Δstate| > 0.4
3. 策略建议: 根据当前状态模式推荐学习策略

干预类型:
- metacog_prompt: 元认知提示
- process_scaffold: 过程支架
- reflection_prompt: 反思引导
- strategy_suggestion: 策略建议
```

**AI生成模块** (`ai_generator.py`)
```python
Anthropic Claude API 集成:
- chat_with_ai(): 对话回复
- generate_intervention(): 生成干预内容
- 支持上下文记忆（历史对话）
- System prompt 包含元认知教学原则
```

## 🔄 完整数据流

```
1. 用户输入 Prompt
   ↓
2. 前端通过 WebSocket 发送
   {
     event_type: "prompt",
     content: "..."
   }
   ↓
3. 后端接收并处理
   a) 保存到 interaction_logs 表
   b) 提取行为特征
   c) 计算元认知状态 S(t) = [p, m, e]
   d) 保存到 metacog_states 表
   e) 推送 state_update 到前端
   ↓
4. 干预决策
   if (需要干预):
     a) 生成干预内容（调用 Claude API）
     b) 保存到 interventions 表
     c) 推送 intervention 到前端
   ↓
5. AI 对话回复
   a) 调用 Claude API 生成回复
   b) 保存对话历史
   c) 推送 ai_reply 到前端
   ↓
6. 前端展示
   - 对话界面：显示 AI 回复
   - 状态面板：更新曲线 + 数值
   - 干预卡片：弹出提示（如触发）
```

## 🎯 核心算法实现

### 元认知状态识别算法

```python
def compute_metacog_state(logs: List[InteractionLog]) -> Dict[str, float]:
    """
    基于最近 N 条交互日志计算元认知状态
    
    输入: 交互日志列表
    输出: {"planning": p, "monitoring": m, "evaluation": e}
    
    算法流程:
    1. 提取行为特征向量 X = [x1, x2, ..., xn]
    2. 应用加权公式计算三维状态
    3. 归一化到 [0, 1] 区间
    4. 返回状态向量 S(t)
    """
    
    # Planning 维度
    planning = min(1.0, (
        prompt_length / 200 * 0.4 +
        question_words / 3 * 0.3 +
        (1 - edit_frequency) * 0.3
    ))
    
    # Monitoring 维度
    monitoring = min(1.0, (
        edit_frequency * 0.5 +
        verify_count / 5 * 0.3 +
        time_consistency * 0.2
    ))
    
    # Evaluation 维度
    evaluation = min(1.0, (
        reflection_words / 5 * 0.6 +
        self_assessment * 0.4
    ))
    
    return {"planning": planning, "monitoring": monitoring, "evaluation": evaluation}
```

### 干预决策算法

```python
def decide_intervention(
    current_state: Dict[str, float],
    history: List[MetacogState]
) -> Optional[InterventionDecision]:
    """
    基于当前状态和历史趋势决定是否干预
    
    决策逻辑:
    1. 检查低水平持续: state < threshold 且持续 N 次
    2. 检查状态波动: |Δstate| > threshold
    3. 模式识别: 分析状态序列模式
    
    返回: InterventionDecision 或 None
    """
    
    # 低水平检测
    for dim in ["planning", "monitoring", "evaluation"]:
        if current_state[dim] < 0.3:
            recent = [h.state[dim] for h in history[-3:]]
            if all(s < 0.3 for s in recent):
                return InterventionDecision(
                    type="metacog_prompt",
                    dimension=dim,
                    reason=f"{dim} 持续低水平"
                )
    
    # 波动检测
    if len(history) >= 2:
        prev_state = history[-1].state
        for dim in ["planning", "monitoring", "evaluation"]:
            delta = abs(current_state[dim] - prev_state[dim])
            if delta > 0.4:
                return InterventionDecision(
                    type="process_scaffold",
                    dimension=dim,
                    reason=f"{dim} 剧烈波动"
                )
    
    return None
```

### 开发环境启动步骤

1. **启动数据库服务**
   ```bash
   # PostgreSQL
   docker run -d --name postgres \
     -e POSTGRES_PASSWORD=password \
     -p 5432:5432 postgres:14
   
   # Redis
   docker run -d --name redis \
     -p 6379:6379 redis:7
   ```

2. **配置后端**
   ```bash
   cd backend
   cp .env.example .env
   # 编辑 .env 填入配置
   python check_env.py
   pip install -r requirements.txt
   python -m alembic upgrade head
   ```

3. **启动后端**
   ```bash
   uvicorn app.main:app --reload
   # 运行在 http://localhost:8000
   ```

4. **启动前端**
   ```bash
   cd frontend
   npm install
   npm run dev
   # 运行在 http://localhost:5173
   ```

5. **验证系统**
   - 访问 http://localhost:5173
   - 创建会话 → 输入消息 → 观察状态更新
   - 检查数据库是否有记录写入
