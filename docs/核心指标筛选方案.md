## 1. 候选指标集（12个）

基于可采集性、理论支撑和计算可行性筛选出的核心指标。

### 1.1 Planning（AI协作前规划）— 4个

| 指标 | 采集方式 | 计算公式 | 理论依据 |
|------|---------|---------|---------|
| **P1. 首次Prompt延迟** | `session.created_at` → 首个`prompt`事件的时间差（秒） | `delay = first_prompt.timestamp - session.created_at` | 反映是否"思考后问"vs"直接问" |
| **P2. Prompt目标明确度** | LLM判断首个Prompt是否包含明确目标 | Haiku判断 → 0/1 | Zimmerman(2002): 目标设定是元认知规划核心 |
| **P3. Prompt任务拆解程度** | 正则匹配首个Prompt中步骤结构 | 统计"先…再""第一步…第二步"等模式 | 体现人机分工意识 |
| **P4. 任务说明首次阅读时长** | 首个`page_view(任务说明)`事件的停留时长（秒） | `duration = page_view.metadata.duration` | 反映对任务的理解投入 |

**观察机会：**
- P1: 会话开始后即可观察
- P2/P3: 需要至少1个Prompt事件
- P4: 需要学生打开任务说明页（可选行为）

**缺失值处理：**
- P1: 若无Prompt则标记为`unknown`
- P2/P3: 同上
- P4: 若无page_view则使用默认值0（不扣分，但降低置信度）

---

### 1.2 Monitoring（AI协作过程监控）— 4个

| 指标 | 采集方式 | 计算公式 | 理论依据 |
|------|---------|---------|---------|
| **M1. AI回复阅读时长** | `ai_reply` → 下一个任意事件的时间差（秒）均值 | `avg(next_event.timestamp - ai_reply.timestamp)` | 区分"秒接受"vs"审慎阅读" |
| **M2. 对话区↔任务区切换频率** | `focus_switch`事件中跨区域切换的密度 | `cross_area_switches / total_events` | 反映人机比较行为 |
| **M3. 追问/澄清比例** | LLM判断Prompt是否为追问/澄清 | `(追问Prompt数 + 澄清Prompt数) / 总Prompt数` | 理解监控的直接证据 |
| **M4. 指出AI错误次数** | LLM判断Prompt是否指出AI错误 | `count(error_pointing_prompts)` | 错误觉察能力 |

**观察机会：**
- M1: 需要至少1个AI回复
- M2: 需要至少2个focus_switch事件
- M3/M4: 需要至少3个Prompt（才能计算比例）

**缺失值处理：**
- M1: 若无AI回复则标记为`insufficient_data`
- M2: 若无切换事件则默认0.1（基线切换率）
- M3/M4: 若Prompt数<3则标记为`insufficient_data`

---

### 1.3 Evaluation（AI协作后评价）— 4个

| 指标 | 采集方式 | 计算公式 | 理论依据 |
|------|---------|---------|---------|
| **E1. AI回复后编辑率** | AI回复后30秒内是否有`edit`事件 | `AI回复后有编辑的次数 / AI回复总数` | 区分"直接用AI"vs"批判性加工" |
| **E2. 编辑内容深度** | LLM判断edit事件描述是结构性vs表层修改 | Haiku判断 → 0/0.5/1，取均值 | Evaluation质量的核心指标 |
| **E3. 自主编辑比例** | 非AI回复触发的edit事件占比 | `非AI触发的edit数 / 总edit数` | 反映人类智力贡献 |
| **E4. 验证行为频率** | `verify`事件密度 | `verify事件数 / 总事件数` | AI输出验证行为 |

**观察机会：**
- E1: 需要至少1个AI回复
- E2: 需要至少1个edit事件
- E3: 需要至少2个edit事件
- E4: verify是用户主动标记行为，可能为0

**缺失值处理：**
- E1: 若无AI回复则标记为`insufficient_data`
- E2/E3: 若无edit则标记为`insufficient_data`
- E4: 若无verify则默认0（不扣分，但降低置信度）

## 2. 特征提取规范

### 2.1 数据预处理

```python
def preprocess_logs(logs: List[InteractionLog]) -> dict:
    """
    从原始日志提取特征
    返回: {特征名: 特征值 或 None}
    """
    # 按server_timestamp排序
    logs = sorted(logs, key=lambda x: x.server_timestamp)
    
    # 去重（根据event_id）
    seen = set()
    deduped = []
    for log in logs:
        if log.event_id not in seen:
            seen.add(log.event_id)
            deduped.append(log)
    
    # 按序号重排（检测乱序）
    if all(hasattr(log, 'sequence_num') for log in deduped):
        deduped.sort(key=lambda x: x.sequence_num)
    
    return extract_features(deduped)
```

### 2.2 特征计算

```python
def extract_features(logs: List[InteractionLog]) -> dict:
    """
    计算12个特征，返回原始值和状态
    """
    features = {}
    session_start = logs[0].session.created_at
    
    # P1: 首次Prompt延迟
    first_prompt = next((e for e in logs if e.event_type == 'prompt'), None)
    if first_prompt:
        features['p1_delay'] = (first_prompt.timestamp - session_start).total_seconds()
        features['p1_status'] = 'observed'
    else:
        features['p1_delay'] = None
        features['p1_status'] = 'unknown'
    
    # P2/P3: LLM判断（异步，缓存）
    if first_prompt:
        features['p2_goal_clarity'] = llm_judge_goal_clarity(first_prompt.content)
        features['p3_decomposition'] = regex_count_steps(first_prompt.content)
        features['p2_status'] = features['p3_status'] = 'observed'
    else:
        features['p2_goal_clarity'] = features['p3_decomposition'] = None
        features['p2_status'] = features['p3_status'] = 'unknown'
    
    # P4: 任务阅读时长
    task_view = next((e for e in logs if e.event_type == 'page_view' and 'task' in e.content), None)
    if task_view and task_view.metadata and 'duration' in task_view.metadata:
        features['p4_reading'] = task_view.metadata['duration']
        features['p4_status'] = 'observed'
    else:
        features['p4_reading'] = 0  # 默认值
        features['p4_status'] = 'not_applicable'
    
    # M1: AI回复阅读时长
    ai_replies = [e for e in logs if e.event_type == 'ai_reply']
    if ai_replies:
        reading_times = []
        for i, reply in enumerate(ai_replies):
            next_event = next((e for e in logs if e.timestamp > reply.timestamp), None)
            if next_event:
                delta = (next_event.timestamp - reply.timestamp).total_seconds()
                if delta < 300:  # 排除异常值（>5分钟视为离席）
                    reading_times.append(delta)
        features['m1_reading'] = sum(reading_times) / len(reading_times) if reading_times else None
        features['m1_status'] = 'observed' if reading_times else 'insufficient_data'
    else:
        features['m1_reading'] = None
        features['m1_status'] = 'insufficient_data'
    
    # M2: 区域切换频率
    switches = [e for e in logs if e.event_type == 'focus_switch']
    cross_area = sum(1 for e in switches if e.metadata and e.metadata.get('is_cross_area'))
    features['m2_switch'] = cross_area / len(logs) if len(logs) > 5 else 0.1
    features['m2_status'] = 'observed' if len(switches) >= 2 else 'insufficient_data'
    
    # M3/M4: Prompt分析
    prompts = [e for e in logs if e.event_type == 'prompt']
    if len(prompts) >= 3:
        followup = sum(1 for p in prompts if llm_judge_followup(p.content))
        error_point = sum(1 for p in prompts if llm_judge_error_pointing(p.content))
        features['m3_followup_ratio'] = followup / len(prompts)
        features['m4_error_count'] = error_point
        features['m3_status'] = features['m4_status'] = 'observed'
    else:
        features['m3_followup_ratio'] = features['m4_error_count'] = None
        features['m3_status'] = features['m4_status'] = 'insufficient_data'
    
    # E1: AI回复后编辑率
    if ai_replies:
        edit_after_ai = 0
        for reply in ai_replies:
            has_edit = any(
                e.event_type == 'edit' and 
                0 < (e.timestamp - reply.timestamp).total_seconds() < 30
                for e in logs
            )
            if has_edit:
                edit_after_ai += 1
        features['e1_edit_rate'] = edit_after_ai / len(ai_replies)
        features['e1_status'] = 'observed'
    else:
        features['e1_edit_rate'] = None
        features['e1_status'] = 'insufficient_data'
    
    # E2: 编辑深度
    edits = [e for e in logs if e.event_type == 'edit']
    if edits:
        depths = [llm_judge_edit_depth(e.content) for e in edits]  # 返回0/0.5/1
        features['e2_depth'] = sum(depths) / len(depths)
        features['e2_status'] = 'observed'
    else:
        features['e2_depth'] = None
        features['e2_status'] = 'insufficient_data'
    
    # E3: 自主编辑比例
    if len(edits) >= 2:
        self_edits = sum(1 for e in edits if not is_triggered_by_ai(e, ai_replies))
        features['e3_self_ratio'] = self_edits / len(edits)
        features['e3_status'] = 'observed'
    else:
        features['e3_self_ratio'] = None
        features['e3_status'] = 'insufficient_data'
    
    # E4: 验证频率
    verify_count = sum(1 for e in logs if e.event_type == 'verify')
    features['e4_verify'] = verify_count / len(logs) if len(logs) > 5 else 0
    features['e4_status'] = 'observed' if verify_count > 0 else 'not_applicable'
    
    return features
```

## 3. 状态计算公式（修订版）

### 3.1 标准化函数

```python
import math

def normalize_linear(value, min_val, max_val, reverse=False):
    """
    线性标准化到[0,1]，连续单调
    reverse=True时，值越大分数越低
    """
    if value is None:
        return None
    value = max(min_val, min(max_val, value))  # clamp
    score = (value - min_val) / (max_val - min_val)
    return 1 - score if reverse else score

def normalize_gaussian(value, optimal, sigma):
    """
    高斯标准化，optimal处得1分，两侧递减
    适用于"有最佳值"的指标
    """
    if value is None:
        return None
    return math.exp(-((value - optimal) ** 2) / (2 * sigma ** 2))

def normalize_threshold(value, threshold, above_better=True):
    """
    阈值标准化，适用于二值判断
    """
    if value is None:
        return None
    if above_better:
        return 1.0 if value >= threshold else 0.3
    else:
        return 1.0 if value <= threshold else 0.3
```

### 3.2 PME计算

```python
def compute_metacog_state(features: dict) -> dict:
    """
    基于特征计算PME三维状态
    返回分数、置信度、状态标识
    """
    
    # Planning
    p1 = normalize_gaussian(features['p1_delay'], optimal=60, sigma=50) if features['p1_delay'] else None
    p2 = features['p2_goal_clarity']  # 已经是0/1
    p3 = normalize_linear(features['p3_decomposition'], 0, 5) if features['p3_decomposition'] is not None else None
    p4 = normalize_gaussian(features['p4_reading'], optimal=120, sigma=100) if features['p4_reading'] else None
    
    p_scores = [s for s in [p1, p2, p3, p4] if s is not None]
    planning_score = sum(p_scores) / len(p_scores) if p_scores else None
    planning_confidence = len(p_scores) / 4  # 观察到的指标占比
    planning_status = 'observed' if len(p_scores) >= 2 else 'insufficient_data'
    
    # Monitoring
    m1 = normalize_gaussian(features['m1_reading'], optimal=15, sigma=20) if features['m1_reading'] else None
    m2 = normalize_gaussian(features['m2_switch'], optimal=0.15, sigma=0.1) if features['m2_switch'] else None
    m3 = normalize_gaussian(features['m3_followup_ratio'], optimal=0.2, sigma=0.15) if features['m3_followup_ratio'] is not None else None
    m4 = normalize_gaussian(features['m4_error_count'], optimal=2, sigma=2) if features['m4_error_count'] is not None else None
    
    m_scores = [s for s in [m1, m2, m3, m4] if s is not None]
    monitoring_score = sum(m_scores) / len(m_scores) if m_scores else None
    monitoring_confidence = len(m_scores) / 4
    monitoring_status = 'observed' if len(m_scores) >= 2 else 'insufficient_data'
    
    # Evaluation
    e1 = normalize_linear(features['e1_edit_rate'], 0, 1) if features['e1_edit_rate'] is not None else None
    e2 = features['e2_depth']  # 已经是0-1
    e3 = normalize_linear(features['e3_self_ratio'], 0, 1) if features['e3_self_ratio'] is not None else None
    e4 = normalize_linear(features['e4_verify'], 0, 0.2) if features['e4_verify'] is not None else None
    
    e_scores = [s for s in [e1, e2, e3, e4] if s is not None]
    evaluation_score = sum(e_scores) / len(e_scores) if e_scores else None
    evaluation_confidence = len(e_scores) / 4
    evaluation_status = 'observed' if len(e_scores) >= 2 else 'insufficient_data'
    
    return {
        'planning': round(planning_score, 3) if planning_score else None,
        'monitoring': round(monitoring_score, 3) if monitoring_score else None,
        'evaluation': round(evaluation_score, 3) if evaluation_score else None,
        'confidence': {
            'planning': round(planning_confidence, 2),
            'monitoring': round(monitoring_confidence, 2),
            'evaluation': round(evaluation_confidence, 2)
        },
        'status': {
            'planning': planning_status,
            'monitoring': monitoring_status,
            'evaluation': evaluation_status
        },
        'feature_coverage': round(len([f for f in features.values() if f is not None]) / 12, 2),
        'features': features  # 保存原始特征值用于审计
    }
```

## 4. 干预触发逻辑（状态机）

### 4.1 状态机定义

```python
class InterventionStateMachine:
    def __init__(self, session_id):
        self.session_id = session_id
        self.state = 'observation'  # observation | cooling | ready
        self.intervention_history = []  # [(type, timestamp), ...]
        self.event_count = 0
    
    def on_event(self, state: dict) -> Optional[dict]:
        """
        每次状态更新时调用
        返回干预内容或None
        """
        self.event_count += 1
        
        # 观察期：前3个事件不干预
        if self.event_count <= 3:
            return None
        
        # 检查冷却期
        now = datetime.utcnow()
        for itype, ts in self.intervention_history:
            if (now - ts).total_seconds() < 180:
                return None  # 仍在冷却
        
        # 检查最大次数
        if len(self.intervention_history) >= 6:
            return None
        
        # 检查触发条件（优先级递减）
        if self._should_intervene_planning(state):
            intervention = self._generate_intervention('planning', state)
            self.intervention_history.append(('planning', now))
            return intervention
        
        if self._should_intervene_monitoring(state):
            intervention = self._generate_intervention('monitoring', state)
            self.intervention_history.append(('monitoring', now))
            return intervention
        
        if self._should_intervene_evaluation(state):
            intervention = self._generate_intervention('evaluation', state)
            self.intervention_history.append(('evaluation', now))
            return intervention
        
        return None
    
    def _should_intervene_planning(self, state: dict) -> bool:
        return (
            state['status']['planning'] == 'observed' and
            state['confidence']['planning'] > 0.7 and
            state['planning'] < 0.4 and
            state['features']['p1_delay'] is not None and
            state['features']['p1_delay'] < 10
        )
    
    def _should_intervene_monitoring(self, state: dict) -> bool:
        return (
            state['status']['monitoring'] == 'observed' and
            state['confidence']['monitoring'] > 0.7 and
            state['monitoring'] < 0.4 and
            state['features']['m1_reading'] is not None and
            state['features']['m1_reading'] < 5
        )
    
    def _should_intervene_evaluation(self, state: dict) -> bool:
        return (
            state['status']['evaluation'] == 'observed' and
            state['confidence']['evaluation'] > 0.7 and
            state['evaluation'] < 0.4 and
            state['features']['e1_edit_rate'] is not None and
            state['features']['e1_edit_rate'] < 0.3
        )
    
    def _generate_intervention(self, dim: str, state: dict) -> dict:
        templates = {
            'planning': {
                'type': 'process_scaffold',
                'content': '在继续之前，请先思考：\n1) 这个任务的核心目标是什么？\n2) 你希望AI帮你完成哪部分？\n3) 你自己需要完成哪部分？'
            },
            'monitoring': {
                'type': 'metacog_prompt',
                'content': '建议：仔细阅读AI的回答，思考：\n1) 是否符合你的预期？\n2) 是否需要进一步澄清？\n3) 有没有不准确的地方？'
            },
            'evaluation': {
                'type': 'reflection_prompt',
                'content': 'AI的输出只是参考，请结合你自己的理解进行修改和完善：\n1) 哪些内容需要调整？\n2) 哪些地方可以加入你的思考？\n3) 如何让内容更符合任务要求？'
            }
        }
        
        return {
            **templates[dim],
            'trigger_reason': f'{dim} score: {state[dim]:.2f}, confidence: {state["confidence"][dim]:.2f}',
            'trigger_state': {
                'planning': state['planning'],
                'monitoring': state['monitoring'],
                'evaluation': state['evaluation'],
                'confidence': state['confidence']
            }
        }
```

```python
            timeout=prompt_config['timeout']
        )
        
        result = float(response.content[0].text.strip())
        
        # 缓存7天
        redis_client.setex(f"llm_judge:{cache_key}", 86400 * 7, str(result))
        
        return result
    
    except Exception as e:
        logger.error(f"LLM判断失败: {task}, {e}")
        return 0.5  # 降级：返回中间值
```

## 6. 实施与验证计划

### 6.1 阶段0：规则基线（当前）

- 使用上述规则+LLM判断
- 无ML模型，直接计算PME分数
- 目标：验证数据采集和特征提取流程

### 6.2 阶段1：数据标注（2周）

招募10-20名学生，收集真实会话：

| 任务 | 样本量 | 标注内容 |
|------|--------|---------|
| 开放性写作（论文引言） | 10会话 | 人工标注每个会话的整体元认知水平（高/中/低） |
| 开放性写作（案例分析） | 10会话 | 同上 |

标注员：2名教育技术专业研究生，独立标注后协商一致。

### 6.3 阶段2：模型训练（1周）

**不训练模型**，改为权重校准：

- 使用逻辑回归找到最优权重组合
- 输入：12维特征
- 输出：PME三维分数（回归）
- 评估指标：与人工标注的相关系数（Pearson r > 0.6为合格）

### 6.4 阶段3：效果评估（4周）

**准实验设计：**

| 组别 | 人数 | 干预策略 | 测量指标 |
|------|------|---------|---------|
| 实验组 | 15 | 接收元认知干预 | PME分数变化、作品质量、学习体验 |
| 对照组 | 15 | 仅使用AI对话，不干预 | 同上 |

**控制变量：**
- 随机分组
- 相同任务（论文引言写作）
- 相同AI模型（Claude 3.5 Sonnet）

**主要终点：**
- 实验组vs对照组的PME分数提升幅度（t检验）
- 作品质量盲评分数（独立评审员，5分制）

**次要终点：**
- 干预查看率（实验组）
- 学生接受度问卷（5分制）

## 7. 已知局限

### 7.1 指标局限

| 局限 | 影响 | 缓解措施 |
|------|------|---------|
| P1可能反映离席而非规划不足 | 误判 | 结合P2/P3/P4综合判断，置信度机制 |
| M1可能反映阅读速度而非监控质量 | 误判 | 结合M3/M4（追问、纠错）综合判断 |
| E3不等于Evaluation能力 | 概念偏移 | 承认这是代理指标，结合E1/E2/E4 |
| LLM判断依赖Prompt质量 | 噪声 | 使用结构化输出、设置超时、降级机制 |

### 7.2 系统局限

- **用户标记依赖**：部分关键事件需要学生主动记录，可能漏报
- **冷启动问题**：会话初期置信度低，无法可靠干预
- **单一任务类型**：仅支持开放性写作，泛化性未验证
