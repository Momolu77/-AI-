## 🗂️ 代码结构导航

### 后端核心文件

```
backend/
├── app/
│   ├── main.py                    ← 应用入口，路由注册
│   ├── database.py                ← 数据库连接配置
│   │
│   ├── api/
│   │   ├── sessions.py            ← REST API：创建/获取会话
│   │   └── websocket.py           ← WebSocket：实时通信
│   │
│   ├── services/
│   │   ├── state_recognizer.py    ← 🔥 核心：元认知状态识别
│   │   ├── intervention.py        ← 🔥 核心：干预决策引擎
│   │   └── ai_generator.py        ← 🔥 核心：AI内容生成
│   │
│   ├── models/
│   │   └── models.py              ← SQLAlchemy 数据库模型
│   │
│   └── schemas/
│       └── schemas.py             ← Pydantic 数据验证模型
│
├── check_env.py                   ← 🛠️ 工具：环境检查
└── test_system.py                 ← 🛠️ 工具：功能测试
```

**关键代码说明**：
- 修改状态识别逻辑 → `state_recognizer.py` 第 50-80 行
- 修改干预触发条件 → `intervention.py` 第 30-70 行
- 修改AI提示词 → `ai_generator.py` 第 10-40 行

### 前端核心文件

```
frontend/
├── src/
│   ├── main.tsx                   ← 应用入口
│   ├── App.tsx                    ← 路由配置
│   │
│   ├── pages/
│   │   ├── HomePage.tsx           ← 主页：创建会话
│   │   └── SessionPage.tsx        ← 🔥 核心：会话界面
│   │
│   ├── components/
│   │   ├── ChatInterface.tsx      ← 🔥 核心：对话组件
│   │   └── StateVisualization.tsx ← 🔥 核心：状态可视化
│   │
│   ├── hooks/
│   │   └── useWebSocket.ts        ← 🔥 核心：WebSocket Hook
│   │
│   └── types/
│       └── index.ts               ← TypeScript 类型定义
│
└── .env                           ← 环境变量配置
```

**关键代码说明**：
- 修改对话界面样式 → `ChatInterface.tsx` 第 100-150 行
- 修改图表配置 → `StateVisualization.tsx` 第 80-150 行
- 修改WebSocket逻辑 → `useWebSocket.ts` 第 30-100 行

## 📖 学习路径

### 新手入门（1-2天）

**第1天：理解系统**
- [ ] 阅读 [README.md](../README.md) 了解整体架构
- [ ] 阅读 [产品设计文档.md](产品设计文档.md) 理解业务逻辑
- [ ] 运行系统，完成 [演示指南.md § 场景1](演示指南.md#场景1-学术写作任务)

**第2天：深入代码**
- [ ] 阅读 [系统实现总结.md](系统实现总结.md) 理解实现细节
- [ ] 调试后端，打断点跟踪 `state_recognizer.py` 的执行
- [ ] 调试前端，观察 WebSocket 消息流

### 进阶开发（3-5天）

**扩展功能**
- [ ] 添加一个新的行为特征（如：复制粘贴次数）
- [ ] 实现一个新的干预类型（如：时间管理提示）
- [ ] 优化状态识别算法（如：引入滑动窗口平均）

**性能优化**
- [ ] 数据库查询优化（添加索引）
- [ ] Redis缓存策略优化
- [ ] 前端渲染优化（虚拟滚动）

### 高级主题（1周+）

**机器学习集成**
- [ ] 收集真实用户数据
- [ ] 人工标注元认知状态
- [ ] 训练分类模型（sklearn/XGBoost）
- [ ] 替换规则引擎为ML模型

**实验验证**
- [ ] 设计对比实验（有干预 vs 无干预）
- [ ] 招募用户进行测试
- [ ] 收集问卷和行为数据
- [ ] 统计分析与效果评估
