# 🚀 元认知自适应学习系统 - 启动指南

## 系统架构

```
前端 (React + TypeScript + Ant Design)
  ↓ WebSocket + HTTP
后端 (FastAPI + Python)
  ↓ 
PostgreSQL (会话/日志/状态持久化)
Redis (状态缓存)
Anthropic Claude API (生成式AI)
```

---

## 📋 前置条件

### 1. 环境要求
- **Node.js**: >= 18.0.0
- **Python**: >= 3.11
- **PostgreSQL**: >= 14
- **Redis**: >= 7.0

### 2. API密钥
- Anthropic API Key (用于 Claude AI)

## 🔧 后端启动

### 1. 进入后端目录
```bash
cd backend
```

### 2. 创建虚拟环境
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

### 3. 安装依赖
```bash
pip install -r requirements.txt
```

### 4. 配置环境变量
创建 `.env` 文件：
```env
# 数据库配置
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/metacog_db

# Redis配置
REDIS_URL=redis://localhost:6379/0

# Anthropic API
ANTHROPIC_API_KEY=sk-ant-xxxxx

# CORS（允许前端访问）
CORS_ORIGINS=["http://localhost:5173"]
```

### 5. 初始化数据库
```bash
# 启动 PostgreSQL 和 Redis（根据你的系统）
# Windows (如果用 Docker):
docker run -d --name postgres -e POSTGRES_PASSWORD=password -p 5432:5432 postgres:14
docker run -d --name redis -p 6379:6379 redis:7

# 运行数据库迁移
python -m alembic upgrade head
```

### 6. 启动后端服务
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

后端将运行在 `http://localhost:8000`

查看 API 文档：
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

```bash

```

## 🐛 常见问题

### 1. WebSocket 连接失败
**症状**: 前端显示「WebSocket未连接」

**解决**:
- 确认后端正在运行（`http://localhost:8000/docs` 能访问）
- 检查浏览器控制台 Network → WS 查看连接错误
- 确认 CORS 配置正确

### 2. 数据库连接失败
**症状**: 后端启动报错 `asyncpg.exceptions.InvalidCatalogNameError`

**解决**:
```bash
# 手动创建数据库
psql -U postgres
CREATE DATABASE metacog_db;
\q

# 重新运行迁移
python -m alembic upgrade head
```

### 3. Redis 连接失败
**症状**: 后端日志显示 `redis.exceptions.ConnectionError`

**解决**:
```bash
# 检查 Redis 是否运行
redis-cli ping
# 应该返回 PONG

# 如果未运行，启动 Redis
redis-server
```

### 4. Anthropic API 调用失败
**症状**: AI 回复超时或报错

**解决**:
- 检查 `.env` 中的 `ANTHROPIC_API_KEY` 是否正确
- 确认 API Key 有剩余额度
- 检查网络能否访问 `api.anthropic.com`
